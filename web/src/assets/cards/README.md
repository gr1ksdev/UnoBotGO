# Cartas decorativas do Mini App

Artes originais utilizadas pelo UnoBotGO, recuperadas sem alteração de pixels a partir dos stickers já referenciados em `internal/telegram/stickers.go`:

| Arquivo | Chave no mapa Stickers |
| --- | --- |
| green-zero.webp | g_0 |
| yellow-zero.webp | y_0 |
| red-zero.webp | r_0 |

Recuperadas em 2026-09-30. WebP transparente, 342 × 512 px. O Vite importa e versiona estas imagens como arquivos estáticos; não há chamadas ao Telegram para a decoração em runtime. Nenhuma credencial, URL autenticada ou consulta de ranking foi incluída neste diretório.

Essas artes são somente decoração, sem significado de gameplay ou interação. Reutilização dos ativos existentes não implica criação de novas artes nem alteração dos stickers do bot.
